# FW-001 — GCSE Prompt Framework

## Purpose

Structure prompts with four required elements: Goal, Context, Source, and Expectation.

## Use when

A prompt must be repeatable, reviewable, source-aware, and clear about its output.

## Definition

- **Goal:** the outcome or task.
- **Context:** the audience, situation, constraints, and relevant background.
- **Source:** the approved material the model should use.
- **Expectation:** the format, quality criteria, boundaries, and review needs.

## Operating rules

Preserve the user's intent, distinguish missing information from optional refinement, require source boundaries where accuracy matters, and end with explicit output expectations. Validate all four elements before use.
