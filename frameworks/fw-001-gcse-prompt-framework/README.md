# FW-001 — GCSE Prompt Framework

Version 2.0.0 · reviewed 2026-09-02

GCSE is a portable structure for writing prompts that are clear, grounded, repeatable, and easy to review:

- **Goal:** the task and desired result.
- **Context:** the purpose, audience, background, and constraints.
- **Source:** the material the system should use.
- **Expectation:** the required form and quality of the response.

## Standard workflow

1. Identify the task, audience, intended source, and desired output.
2. Map the request into Goal, Context, Source, and Expectation.
3. Replace every bracketed placeholder with usable information.
4. Check privacy, source grounding, assumptions, and decision boundaries.
5. Review the generated response before using or sharing it.

The framework improves direction and usefulness; it does not guarantee correctness.
