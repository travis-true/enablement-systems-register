# GCSE example prompts

These examples use fictional, low-risk scenarios and can be adapted to different tools.

## Email-thread summary

```text
Goal

Summarize the email thread and identify action items assigned to me.

Context

I need to get current quickly and avoid missing a commitment.

Source

Use only the email thread provided with this prompt.

Expectation

Write three summary bullets, followed by a table with Action, Owner, and Due date. Use “Not stated” when an owner or date is absent; do not infer one.
```

## Meeting recap

```text
Goal

Create a concise record of the meeting's outcomes.

Context

The recap is for participants and absent team members who need decisions, actions, and unresolved questions.

Source

Use the attached meeting transcript and notes. If they conflict, identify the conflict.

Expectation

Provide five summary bullets, then sections for Decisions, Action items, and Open questions. Include owners and due dates only when stated in the sources.
```

## Document outline

```text
Goal

Create an outline for a beginner-friendly reference about the process described in the notes.

Context

The audience is new team members. The reference should support first-time task completion without live assistance.

Source

Use only the supplied process notes.

Expectation

Return section headings with one or two bullets each. Include prerequisites, numbered steps, verification, and troubleshooting. Provide an outline, not a full draft, and flag source gaps.
```

## Data analysis

```text
Goal

Identify the most important patterns in the dataset.

Context

The result will support a short leadership discussion about recent performance.

Source

Use the named worksheet and the date range shown in the table.

Expectation

Provide three supported trends, one outlier to investigate, and one concise summary sentence. Cite the relevant columns or ranges and do not claim causation from correlation.
```
