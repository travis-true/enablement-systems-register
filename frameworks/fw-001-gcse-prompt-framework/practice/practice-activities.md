# GCSE practice activities

## 1. Strengthen a weak prompt

Rewrite `Summarize this` by adding:

- the specific outcome;
- the audience or purpose;
- the exact source; and
- the required format and length.

## 2. Diagnose the missing element

Review a generic or unusable AI response. Decide whether the prompt needed a clearer Goal, more Context, a stronger Source, or a more precise Expectation. Revise only the element that would most improve the result.

## 3. Refine a first response

Write two follow-up prompts that improve the result without restarting. Possible refinements include shortening the response, focusing on decisions, adapting it for a new audience, or adding a next step.

## 4. Apply GCSE to real work

Choose a low-risk task. Draft a four-part prompt, run it, and compare the response with the criteria in Expectation.

## Self-check

- The Goal states one clear outcome.
- Context includes the audience or reason.
- Source identifies the material to use.
- Expectation defines the response form and quality.
- Unsupported details are not requested or accepted as facts.
- The response is reviewed before use.
