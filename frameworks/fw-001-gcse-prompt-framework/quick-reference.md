# GCSE quick reference

| Element | Meaning | Ask yourself | Simple example |
|---|---|---|---|
| **Goal** | Action and result | What should be done? | Summarize the decisions and action items. |
| **Context** | Purpose and situation | Who is it for, why, and what matters? | Prepare a quick update for project sponsors. |
| **Source** | Grounding material | What information should be used? | Use the attached meeting transcript. |
| **Expectation** | Definition of success | What form and quality are required? | Use five bullets, then a table of owners and due dates. |

## Six habits

1. Be specific.
2. Include relevant context.
3. Reference a source whenever possible.
4. Define the output.
5. Refine with follow-up prompts.
6. Review before sharing.

## Common problems

| Problem | Fix |
|---|---|
| Vague task | Start Goal with a precise action verb. |
| Generic response | Add the purpose, audience, and constraints to Context. |
| Unsupported details | Supply a Source and prohibit invention. |
| Unusable format | Specify length, structure, and tone in Expectation. |
| Conflicting instructions | State which source or requirement has priority. |
| Too many tasks | Split unrelated goals into separate prompts. |

## Final review

- Is the goal specific?
- Is the audience or reason clear?
- Is the intended source named or supplied?
- Is the output format and quality defined?
- Are gaps and assumptions visible?
- Has sensitive information been minimized?
- Will a person verify the response before use?
