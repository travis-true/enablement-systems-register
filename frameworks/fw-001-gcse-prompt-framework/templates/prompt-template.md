# GCSE prompt template

```text
Goal

[What should the system do, and what result is needed?]

Context

[Why is this needed? Who is it for? What background, terminology, timeframe, standards, or constraints matter?]

Source

[What selected text, file, message, transcript, webpage, table, dataset, or notes should the system use?]

Expectation

[What format, length, structure, tone, detail, required sections, exclusions, and quality criteria define success? Identify missing or conflicting information; do not invent unsupported facts.]
```

Before submitting, replace every bracketed placeholder and remove instructions that do not apply.
