# FW-004 — EnablementOps Framework

## Purpose

Describe the capabilities required to run a sustainable enablement function.

## Capability areas

Training-needs analysis; intake and triage; governance and version control; content inventory and taxonomy; lifecycle management; analytics and KPIs; AI governance; change management; knowledge-base and support integration; search and discoverability.

## Current gap

Define maturity levels, accountable owners, measures, dependencies, and an adoption roadmap for each capability.
