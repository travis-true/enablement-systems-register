# PB-004 — Freelance Learning-Service Gig Build

## Purpose

Convert a learning or enablement service into a clearly positioned, scoped, priced, and visually credible marketplace offer.

## Draft flow

1. Define the buyer, problem, outcome, and boundaries.
2. Write the title, category, metadata, and supported search terms.
3. Design three distinct packages with delivery time and revision limits.
4. Add useful, separately scoped extras.
5. Build the description, FAQ, and structured intake questions.
6. Create compliant images and portfolio PDFs.
7. Run content, visual, scope, pricing, and platform QA.
8. Publish and measure inquiries, conversion, effort, and revisions.

## Completion gaps

Standardize the QA checklist and capture evidence from another end-to-end use.
