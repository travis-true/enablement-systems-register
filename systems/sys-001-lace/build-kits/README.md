# LACE format-specific build kits

These are the approved pilot-ready production kits for SYS-001.

| Template | Build kit | Decision-engine asset type | Pilot use |
|---|---|---|---|
| LACE-TMP-100 | Task-Based Job Aid | `task-based-job-aid` | Supported alternative and inherited LACE format |
| LACE-TMP-101 | Compact Quick Reference Guide | `compact-quick-reference-guide` | QRG pilot |
| LACE-TMP-102 | Detailed Procedural Guide | `standard-operating-procedure` or `knowledge-article` requiring detailed instruction | Detailed-guide pilot |
| LACE-TMP-400 | Instructional Multimedia Package | `demonstration-video` | Multimedia pilot |

## Required use

1. Begin with an approved LACE-TMP-009 Asset Decision Record.
2. Create and approve LACE-TMP-005 Asset Build Specification.
3. Select the matching registered build kit and variant.
4. Copy the kit template; never edit the canonical template.
5. Apply the profile’s required sections, rules, outputs, and acceptance criteria.
6. Preserve source IDs and record every unsupported or unresolved item.
7. Render the editable source into the intended distribution format.
8. Inspect every rendered page or media segment.
9. Resolve all Critical and Major defects.
10. Achieve a visual score of at least 95/100 and pass the broader package gate.
11. Record the approved release package in LACE-TMP-008.

## Boundary

The build kit controls required production behavior, not organization-specific branding, platform policy, or publishing authority. Apply only approved local standards and preserve those requirements in the asset build specification.

Assets without an active matching kit require a documented human-approved production plan. They must not borrow another template ID merely because the layouts appear similar.
