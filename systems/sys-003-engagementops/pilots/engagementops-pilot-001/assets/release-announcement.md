# EnablementOps v1.0.0 is available

EnablementOps is now a governed operating system for managing enablement work from need through production, quality, lifecycle, and maintenance.

Use it when you need to determine how enablement work should be requested, prioritized, designed, produced, delivered, measured, or maintained.

[Review EnablementOps v1.0.0](../../../sys-002-enablementops/README.md)

EngagementOps supports awareness and participation when coordinated engagement is required; it does not replace EnablementOps or prove capability.
