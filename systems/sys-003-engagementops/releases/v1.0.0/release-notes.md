# EngagementOps v1.0.0 release notes

**Release date:** 2026-09-03  
**System:** SYS-003 — EngagementOps  
**Release type:** First governed production release

## Included capabilities

- Optional, trigger-based activation linked to EnablementOps.
- Controlled authority, source, risk, approval, exception, and lifecycle rules.
- Reusable campaign, asset, channel, measurement, localization, readiness, handoff, registry, and calendar records.
- Eight channel profiles and twelve controlled metrics across six evidence levels.
- P0/P1 delivery gates, accessibility, privacy/redaction, rights, localization, and post-change controls.
- Human-readable Markdown and machine-readable YAML/JSON export contracts.
- Eleven schemas, semantic validation, negative tests, CI enforcement, and pilot discovery.
- EO-PILOT-001 public-safe end-to-end evidence.

## Release boundary

SYS-003 v1.0.0 is approved as the current EngagementOps operating system. It remains optional. This release does not authorize a future campaign, distribution channel, audience tracking, personal-data collection, specialist determination, or publication action.

## Pilot limitation

EO-PILOT-001 verified the governed repository-publication path. It did not establish verified reach, engagement, learning, adoption, performance, sustainment, or causal impact.

## Compatibility and rollback

SYS-001 and SYS-002 remain separate authorities. Canonical IDs are unchanged. The v0.7.0 baseline remains recoverable through Git history. Roll back by reverting the release changes without reusing or renumbering identifiers.
