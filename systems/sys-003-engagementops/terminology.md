# EngagementOps controlled terminology

| Term | Controlled meaning |
|---|---|
| Activation | The governed decision to use EngagementOps for an approved engagement need. |
| Engagement | An observable audience response or continued interaction tied to an approved objective. |
| Awareness | Evidence that the intended audience had a reasonable opportunity to encounter the message. |
| Participation | A defined audience action such as registering, attending, enrolling, responding, contributing, or using a resource. |
| Touchpoint | One governed audience interaction within a sequence. |
| Channel | An approved delivery environment with its own owner, format, accessibility, privacy, and measurement requirements. |
| Campaign | A coordinated, time-bound set of touchpoints serving one approved engagement objective. |
| Call to action | The specific, observable action requested of an audience. |
| Reinforcement | A follow-up touchpoint intended to renew attention or participation; it does not by itself prove learning transfer. |
| Sustainment | Continued engagement activity after launch under defined ownership, cadence, measures, and exit criteria. |
| Conversion | Completion of the approved call to action, not proof of capability or business impact. |
| Engagement measure | A defined indicator of reach, response, participation, or continuation, interpreted within its stated limitations. |
| Deactivation | The governed closure, withdrawal, or transition of EngagementOps activity. |
| EnablementOps | SYS-002, which owns capability and performance enablement. |
| LACE | SYS-001, which owns governed learning-asset construction and asset-specific QA. |
