# Annotation and accessibility standard

Annotations direct attention; they do not replace instructions.

## Approved patterns

- Numbered callout for an ordered sequence.
- Short text label for a named target.
- High-contrast focus box for one region.
- Focused crop when surrounding context is unnecessary.
- Neutral dim overlay that preserves readable orientation.
- Matched before/after pair for a state change.

## Rules

Use numbers that match adjacent steps. Keep labels short and outside the interface when practical. Do not cover controls, text, selection states, error messages, or keyboard focus. Avoid crossing leader lines and ambiguous endpoints. Split the image when density reduces legibility.

Color cannot be the only cue. Use shape, label, number, or position with sufficient contrast. Verify the final placement size, not only the source canvas.

## Text alternatives

Adjacent instructions must fully explain the action. Alt text states the image purpose and essential visual state, normally in one or two concise sentences. Provide a structured long description when relationships or comparisons are not fully conveyed nearby. Decorative screenshots are omitted rather than assigned empty alt text when they duplicate no necessary information.
