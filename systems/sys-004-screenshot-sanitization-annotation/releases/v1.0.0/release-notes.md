# SYS-004 v1.0.0 release notes

Initial governed release of the Screenshot Sanitization & Annotation System.

Added:

- system boundary, lifecycle, roles, states, and hard stops;
- privacy inspection and opaque replacement controls;
- annotation and accessibility rules;
- seven-dimension QA gate and defect severity;
- reusable specification template;
- JSON Schema and synthetic example record;
- automated validation and regression tests;
- public-safe pilot and completion evidence.

Operational working files and screenshots remain outside the repository.
