# WF-001 — Training Request Intake and Triage

## Trigger and outcome

An enablement request enters a guided intake and exits as a reviewable issue with structured data and retained draft files.

## Flow

1. Capture the request and requester-defined need.
2. Apply conditional questions based on request type.
3. Save or resume a local draft when needed.
4. Generate machine-readable JSON and human-readable Markdown.
5. Submit a prefilled GitHub issue for human review.
6. Triage, clarify, prioritize, and authorize work.

Governed implementation details remain in the L-D-OS repository.
